# PixelWerk – Bildbearbeitung

Verkaufsorientierte One-Page-Website für einen digitalen Bildbearbeitungs-Service.

## Ziel

Die Website ist auf direkte Anfragen statt auf reine Selbstdarstellung optimiert:
- klare Leistungen
- sichtbare Einstiegspreise
- Vorher/Nachher-Portfolio
- mehrere Call-to-Actions
- einfaches Anfrageformular
- responsive Darstellung

## Vor dem Einsatz

1. `index.html` öffnen.
2. `DEINE-EMAIL@BEISPIEL.DE` in `index.html` durch die echte Geschäftsadresse ersetzen.
3. Eigene Portfolio-Bilder einsetzen, sobald echte Kundenbeispiele vorhanden sind.
4. Impressum und Datenschutzerklärung ergänzen, bevor die Seite öffentlich geschäftlich eingesetzt wird.

## Deployment

Die Seite ist statisch und benötigt keinen Build-Prozess. Sie kann direkt auf GitHub Pages, Vercel oder einem anderen Static Host veröffentlicht werden.
